# Pointwise Support

Pointwise helps software teams estimate GitHub issues together and compare their result with an advisory GitHub Copilot review.

## Languages

Pointwise supports **English, French, German, Spanish, Italian, Dutch, Polish, Japanese, Korean and Simplified Chinese**.

The application automatically uses a supported browser language and falls back to English when the browser preference is not supported. Pointwise-owned server and API messages follow supported `Accept-Language` preferences with the same English fallback.

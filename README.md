# Pointwise Support

Public support, privacy and security information for [Pointwise](https://github.com/ark-whale-applications/pointwise).

## Language support

Pointwise supports English, French, German, Spanish, Italian, Dutch, Polish, Japanese, Korean and Simplified Chinese.

The application automatically selects a supported language from the browser's language preferences and falls back to English when necessary. Pointwise-owned server and API messages also use supported `Accept-Language` preferences with English fallback.

## Get support

[Open a support request](https://github.com/ark-whale-applications/pointwise-support/issues/new)

Before posting, remove access tokens, passwords, private source code, personal information and confidential repository content.

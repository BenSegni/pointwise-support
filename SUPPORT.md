# Pointwise Support

For help with Pointwise, [open a GitHub issue](https://github.com/BenSegni/pointwise-support/issues/new).

Include:

- a short description of the problem;
- the steps that led to it;
- what you expected to happen;
- what happened instead; and
- screenshots or error messages with sensitive information removed.

Do not post passwords, access tokens, private source code, personal information or confidential repository content. For a privacy or deletion request, provide only enough information to arrange a private contact route.

# Pointwise Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, access tokens, private source code or confidential repository content in a public issue.

Open a minimal [support request](https://github.com/BenSegni/pointwise-support/issues/new) stating that you need to report a security concern, without including sensitive technical details. A private contact route will then be arranged.

## Scope

Reports concerning the Pointwise application, authentication, authorisation, data handling or GitHub integration are welcome. Please provide enough information to reproduce and assess the issue once a private channel has been established.
